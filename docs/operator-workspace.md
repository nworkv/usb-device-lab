# Единый интерфейс оператора

Точка запуска прежняя: python -m usb_device_lab.dashboard serve --config lab.toml --port 8765.
После установки изменений перезапустите процесс сайта и обновите страницу.
Четыре вкладки переключаются внутри страницы. Токен хранится только в памяти;
выход отменяет запросы и очищает интерфейс, но НЕ останавливает кампанию.

Запуск использует пустую команду и перечитывает lab.toml. Число попыток, длительность
и начальное значение генератора показываются только для чтения. Переопределения
через новый UI API отклоняются. Изменение только параметров кампании применяется
при новом запуске; смена подключения/путей требует перезапуска сайта. Продолжение
отклоняется, если параметры файла не совпадают с сохранёнными. Legacy API остаются
совместимыми; данное ограничение касается нового интерфейса.

Обновление раз в 3 секунды без перекрывающихся циклов. Результаты показывают
последние 100 попыток, ошибки вынесены отдельно (последние 100 попыток с ошибками).
Выбор истории кампании общий для результатов и логов. Старая БД без tracking
показывается как «Ранее сохранённые попытки». Логи автоматически открывают текущую/
последнюю попытку; старую можно выбрать по номеру и времени, без ввода ID.
Исходные сообщения и JSON сохраняют оригинальный язык, подписи UI русские.
Корпус общий для стенда, не отдельная копия для каждой кампании.

Скачивание через authenticated fetch и attachment, без токена в URL. Проверяется
принадлежность попытки кампании, allowlist и отсутствие симлинков для runs/run/file.
Файл передаётся целиком на момент открытия, до 64 МиБ, иначе 413 без усечения.
Если файл уменьшается при передаче, скачивание может оборваться: повторите после
остановки. Полный lab.toml не экспортируется. Логи/конфигурации могут содержать
чувствительные сведения; автоматическое удаление секретов не реализовано.

Для нового results API нужны JSON-функции SQLite. Производственный граф остаётся
прежним, DashboardServer не удалён: serve использует новый WorkspaceServer.

9 целевых тестов прошли при подготовке: HTTP/SQLite и JS в Node.js с подставным DOM.
Базовый сервер, supervisor, загрузчик конфигурации, checkpoint/corpus и tail reader
были изолированными заменами. Полный checkout, CI, реальная браузерная отрисовка и
физический стенд не проверены. Синтаксис Python/JS проверен. Тесты импортируют
настоящий WorkspaceServer на полном checkout; CI должен подтвердить этот прогон.

Запуск: python -m unittest discover -s tests -p 'test_workspace*.py' -v.

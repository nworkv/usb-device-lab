# Единая локальная точка запуска

Из корня репозитория с настроенным lab.toml:

```sh
python -m usb_device_lab.dashboard check --config lab.toml
python -m usb_device_lab.dashboard serve --config lab.toml --port 8765
```

Команды init/check/fuzz/replay передают аргументы прежнему lab CLI без изменений.
Например, dashboard init --help показывает параметры создания конфигурации.
Старые точки запуска не удалены; запускать несколько панелей на одном порту не нужно.
При запуске serve проверяется конфигурация, создаётся persistent/event supervisor,
но кампания автоматически не стартует. Проверки стенда выполняются перед кампанией
через существующий run_session. check следует запускать отдельно перед работой.

На одном origin доступны разделы / (управление), /events (события) и /results
(сводка сохранённых попыток). Навигация не передаёт токен в URL и не сохраняет его
в браузере: после перехода между страницами введите токен снова. HTML/CSS/JS не
содержат приватных данных; API требует bearer-токен и проверки Host/Origin.
Раздел событий автоматически включает опрос журнала при наличии введённого токена.
Все страницы используют локальные ресурсы и прежнюю политику CSP.

GET /api/results?offset=0 читает runs.sqlite3 в mode=ro, возвращая до 50 сводок.
Параметр offset ограничен 0..10000000; дубли и неизвестные поля отклоняются.
Отсутствие БД до первой кампании означает пустой список, а не создание БД.
Ответ содержит только идентификатор, статус, время, outcome, confirmation,
new_pcs и summary_limited, без сырых логов. Сводка использует существующий run_view
и не превращает kernel_candidate в подтверждённый баг. Для result больше 2 MiB
сводка помечается inconclusive/summary_limited, без разбора полного JSON.
Детальные артефакты остаются в прежнем read-only просмотрщике; этот коммит не
переносит его полностью и не добавляет визуализацию корпуса или хвост логов.

```sh
python -m unittest discover -s tests -p 'test_dashboard.py'
```

Восемь тестов прошли при подготовке с реальными SQLite/HTTP и изолированными
базовыми HTTP-компонентами, подставным supervisor и проверенной реализацией
run_view. Проверен синтаксис JavaScript страницы результатов. Полный lifecycle
serve, существующие команды lab на реальном окружении, браузер, полный набор
тестов, SSH/KCOV и физический стенд не проверены.

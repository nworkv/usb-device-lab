# Русская панель управления

Панель использует русские подписи, карточки состояния, количества завершённых
попыток и идентификатора сессии. Добавлены адаптивная стеклянная тема, локальный
CSS, подсказки, автоматическое обновление состояния каждые 2 секунды и технические
данные в раскрывающемся блоке. Все ресурсы выдаёт локальный HTTP-сервер.

Существующие точки запуска сохраняются:

```sh
python -m usb_device_lab.control_http --config lab.toml --port 8765
python -m usb_device_lab.persistent_control --config lab.toml --port 8765
python -m usb_device_lab.event_control --config lab.toml --port 8765
```

Выберите одну точку запуска, не запускайте все три одновременно. Этот коммит
меняет общую основную панель, но не объединяет CLI и не заменяет просмотрщик
результатов. Дополнительный виджет событий пока сохраняет прежние подписи.

Токен не встраивается в HTML и не сохраняется в browser storage. API по-прежнему
защищён bearer-токеном и проверкой Host/Origin; CSS публичен, но содержит только
оформление. CSP разрешает стиль только с собственного origin, без unsafe-inline.
Вывод состояния и ошибок использует textContent. Кнопки блокируются на время
запроса. API и backend остаются прежними. Для точной передачи seed интерфейс
ограничивает ввод диапазоном Number.isSafeInteger; API поддерживает прежний
диапазон. Числовые ограничения окончательно проверяет backend.

Остановка завершает текущую попытку; возобновление создаёт новую сессию. Панель
прямо предупреждает, что failed не подтверждает ошибку ядра. Технические сообщения
backend могут оставаться на английском; основные подписи и сообщения UI русские.

```sh
python -m unittest discover -s tests -p 'test_panel_ui.py'
```

Семь тестов прошли при подготовке: реальные HTTP-маршруты/CSP/авторизация,
HTML-контракт и JavaScript в Node.js с подставным DOM/fetch. Проверен синтаксис JS.
Тест Node.js пропускается, если Node.js не установлен. Браузерный визуальный
прогон, реальный supervisor, полный набор тестов и физический стенд не проверены.
Исходный control_http.py сверен с Git blob SHA перед построением патча.
